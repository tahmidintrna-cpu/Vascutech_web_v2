# VascuTech website

Static site. No build step.

- `index.html` Home
- `vascuai.html` VascuAI
- `dualvein.html` DualVein
- `about.html` About and collaborate
- `style.css` shared styles
- `assets/` logos, photos, demo video

To publish with GitHub Pages: upload everything in this folder to the root of the repository, then go to Settings > Pages and choose the main branch, root folder.
